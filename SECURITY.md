# Security reporting

Include the exact component and Home Assistant versions and a minimal synthetic reproduction. Do not post raw diagnostics, tokens, serials, MAC/IP addresses, unique IDs, room names, maps or household logs publicly. Ask the maintainer for a private reporting channel before sharing sensitive material, or use GitHub private vulnerability reporting when enabled.

Keep a backup before upgrading or changing stored settings. Test with synthetic robots first; do not command a real robot solely to reproduce a software defect. Report permission, script injection, unsafe storage and diagnostics-redaction defects as security issues.
